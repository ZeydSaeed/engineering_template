== Defects found and fixed during the phase
1. PostgreSQL session time zone (Asia/Baghdad) differed from the
   application's (UTC). Times Laravel writes without an offset were shifted
   three hours: a password reset token issued a second earlier was already
   expired. Fixed with 'timezone' => 'UTC' on the pgsql connection; guarded
   by a test.
2. migrate:fresh drops tables but not functions, so the audit migration's
   CREATE FUNCTION failed on every second run (RefreshDatabase). Fixed with
   CREATE OR REPLACE FUNCTION. The failed runs had also left connections
   open until the owner role's limit (10) was reached; the limit was not
   raised and the problem did not recur.
3. Registration as a runtime switch broke the frontend build: route helpers
   are generated from registered routes, and register.tsx imported a helper
   that no longer existed. Registration is now removed in code (ADR-0015).
4. scripts/db/create-local-databases.ps1 failed after creating the roles,
   when writing a credential file that did not exist yet (an empty array
   became $null). Fixed and unit-checked on scratch files; the second run
   succeeded and rotated all three passwords.
