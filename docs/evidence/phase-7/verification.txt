Phase 7.1 verification - design system foundation (ADR-0024)
Machine: local development PC (Windows 10, PHP 8.5.12, Node 24, Chromium
headless shell 158 via Playwright 1.65, axe-core 4.14)
Date: 2026-11-12

Implemented
- Arabic/RTL and English/LTR: SetLocale (cookie, validated), <html lang dir>,
  DirectionProvider, logical CSS properties throughout, sidebar on the
  reading side, mirrored arrows, language switcher (welcome, sign-in pages,
  appearance settings).
- 135 interface strings in lang/ar.json; lang/ar/{auth,passwords,
  pagination,validation}.php.
- Tokens: semantic colours light/dark incl. success/warning/info; raw
  palette colours removed from application components; reduced motion.
- Font IBM Plex Sans Arabic (OFL 1.1) self-hosted; bunny.net removed.
- Neutral logo and favicons replace the Laravel marks.
- Dashboard: welcome and a reusable EmptyState (improvement #13).

Defects found and fixed
- The theme script in the root view had no CSP nonce: blocked in every
  browser since the CSP went live (ADR-0016). Now carries the nonce; tested.
- The appearance cookie (unencrypted) reached an inline script unchecked;
  now limited to light/dark/system and passed through @json; tested.
- axe found WCAG AA contrast failures (appearance tabs, delete-account
  warning, error and status text) from raw palette colours; replaced with
  tokens.
- Starter-kit links to Laravel's repository and docs removed from the
  sidebar and header.
