== Defects found and fixed during the phase
1. FileStore deleted a file's bytes on any exception, including one raised
   after the record had committed (queueing the scan). With the queue down
   that would have left a committed record without its file. The scan is now
   queued after the transaction, outside the clean-up; a test simulates the
   queue failing after the commit and checks the record and bytes remain.
2. Circuit-breaker counting used Cache::increment on a missing key, which
   some stores do not create; the counter is now created with add() first.
3. The architecture rules flagged tempnam() in the spreadsheet check
   (security preset); it now uses tmpfile(), created with a unique name and
   removed on close.

== Test mistakes corrected (not product defects)
- A test route lacked the middleware that binds {file} to a record.
- Http::fake records no request whose handler throws, and fakes add up
  rather than replace; the circuit test counts calls itself.
