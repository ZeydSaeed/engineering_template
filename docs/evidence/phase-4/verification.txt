== Defects found and fixed during the phase
1. Outbox topics contain dots (test.counted); looking a topic up with
   config("platform.outbox.handlers.{$topic}") read the dot as nesting and
   never found the handler. Topics are now looked up as plain keys
   (Outbox::handlerFor).
2. The relay's first draft deferred the queue push to after the response.
   With after_commit on, a push failing after the relay's commit would have
   lost a message already marked as dispatched. The relay now pushes before
   its commit, in a savepoint per message.
3. Fortify keyed its used-code store by the code alone; two users typing the
   same code in one window collided (Phase 3 finding). Replaced by
   UserScopedTwoFactorProvider (secret + code); TwoFactorCodeReuseTest shows
   Fortify's provider refusing and ours accepting the second user, and ours
   still refusing a replay by the same user.
