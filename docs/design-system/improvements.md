# Phase 7: the 28 interface improvements

The list and priorities come from the Phase 0 report (section 7). Each row
is updated in the batch that changes it. An item is **Done** only with a
passing automated test and the evidence named; **Partial** says what is
missing.

Statuses: Done · Partial · Planned (batch) · NOT TESTED (manual check
outstanding, see [manual-tests.md](manual-tests.md)).

Common checks for every shared component (in addition to its own tests):
the component gallery `/ui` and the pages that use it pass
`tests/browser/pages.spec.ts`: Arabic/RTL and English/LTR, light and dark,
phone (390), tablet (820) and desktop (1366) widths, axe WCAG 2.2 A/AA with
zero violations, no horizontal overflow. Translations are enforced by
`TranslationsTest`, colours by `DesignTokensTest`.
